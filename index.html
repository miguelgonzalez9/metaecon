Protocol

The methodological decisions of your review, made explicit up front. Everything downstream — search filters, screening criteria, the extraction instructions sent to the model — is generated from this page.

These choices are saved with the project file and stamped into the provenance log — reviewers can audit exactly what the machine was told.

Extract estimates

One model call per paper against a fixed JSON schema: every reported estimate of your target parameter, with coefficient, standard error, specification, and a confidence flag. Numbers are stored exactly as printed. You can always add or edit estimates by hand.
